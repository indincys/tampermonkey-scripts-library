# Tampermonkey Scripts Library

个人油猴脚本仓库（`油猴脚本库`）。

用途：
- 存放每个独立脚本文件（一个文件一个功能）
- 按版本持续更新
- 记录每次改动的行为变化点

## Scripts

- `scripts/视频快捷键精简版-Enter-ShiftEnter-ZXC.user.js`
  - 功能：`Enter` 全屏自动播放、`Shift+Enter` 网页全屏、`Z/X/C` 倍速控制

- `scripts/YouTube-四列极简布局.user.js`
  - 功能：YouTube 视频网格每行 4 列（极简版）

## Maintenance Notes

每次改动建议记录以下内容（按你的规则）：

- `新增`
- `删除`
- `修改`
- `关键改动点`（哪一段逻辑改变了行为、为什么必须这么改）

## Versioning

- 修复问题：`0.1.0 -> 0.1.1`
- 小功能调整：`0.1.x -> 0.2.0`
- 大改/不兼容变更：`0.x -> 1.0.0`
